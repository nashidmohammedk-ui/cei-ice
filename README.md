# cei-ice

CEI — Haute Glacerie & Artisanal Gelato Luxury E-Commerce Website.

### Features
- **Hero Section**: 1080p Cinema Flavour Transformation film with interactive audio/video controls.
- **Handheld Couture Portfolio**: 8 Signature Bar Flavours with interactive 3D Exploded-View Ingredient Reveal System.
- **Flavour Customizer**: Interactive Atelier Dipping Salon customizer.
- **Shopping Cart & Checkout**: Seamless cart drawer and luxury boutique booking.
